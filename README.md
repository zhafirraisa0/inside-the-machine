# Inside the Machine — From Bits to Brains

An interactive, beginner-friendly computer science learning website. It introduces digital bits, binary numbers, logic gates, processor concepts, device components, and a step-by-step model of how data moves when a person opens an application.

## Technologies
- HTML5
- CSS3 (responsive layout and animations)
- JavaScript (interactive lessons and simulations)
- Three.js loaded from a CDN for the 3D hardware viewer
- Google Fonts loaded from Google Fonts CDN

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).
3. An internet connection is needed for the Three.js library and web fonts. If the 3D library cannot load, the site is designed to show its fallback illustration where available.

## Publish as a live website
### Netlify Drop
1. Go to https://app.netlify.com/drop and sign in.
2. Extract this ZIP first.
3. Drag the `InsideTheMachine_Submission_Package` folder (the folder containing `index.html`) onto Netlify Drop.
4. Wait for deployment and open the generated live URL.
5. Test the URL on both a laptop and a phone before submitting.

### GitHub Pages
1. Create a public GitHub repository for the project.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**, choose deployment from the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the URL, then test it on mobile and desktop.

## Notes
This project is an educational visualization, not a manufacturer-accurate CAD model or an exact hardware diagnostic tool. The device models and data-flow sequence simplify real systems for learning. The 3D viewer requires WebGL support and internet access to load Three.js from its CDN.
