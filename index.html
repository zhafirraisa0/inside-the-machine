PANDUAN PEMULA

Memahami angka biner dari nol

Komputer menggunakan dua simbol: 0 dan 1. Setiap simbol disebut bit. Delapan bit membentuk satu byte.

01

Apa arti 0 dan 1?

Bayangkan sakelar: 0 berarti mati dan 1 berarti menyala. Ini model sederhana untuk memahami dua keadaan digital.

02

Setiap posisi punya nilai

Dari kanan ke kiri, nilai bit selalu dua kali lipat: 1, 2, 4, 8, 16, 32, 64, lalu 128.

03

Jumlahkan posisi yang bernilai 1

Bit bernilai 1 ikut dijumlahkan. Bit bernilai 0 tidak menambah nilai.

NILAI TEMPAT 8 BIT
1286432168421
Kiri = nilai terbesar · kanan = nilai terkecil
CONTOH LANGKAH DEMI LANGKAH

00000101 berarti 5

Hanya posisi 4 dan 1 yang menyala. Jadi, 4 + 1 = 5.

Inside the Processor

Thousands of logic gates combine to form a processor, anchored by four foundational pillars.

01 / UNIT

Control Unit

Directs data flow and instruction execution across the processor.

02 / CORE

ALU

Ultra-fast tiny storage holding active working data.

04 / RAM

Memory
